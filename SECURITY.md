# Security

This app manages local login credentials. Keep portable folders private and protect access to
your Windows account. Authentication files are not encrypted by this app.

Do not post credentials, tokens, session contents or personal filesystem paths in public issues.
For a vulnerability involving credential exposure or unsafe file operations, use this repository's
GitHub **Security → Report a vulnerability** feature if enabled. If it is unavailable, open an
issue asking for a private contact channel without publishing exploit details or sensitive data.

Security fixes target the latest release. No older-version support commitment is currently made.
Never delete a used portable tree through an unverified recursive command: remove accounts from
the app first so their shared-session junctions are detached safely.
